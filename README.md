# عيد أبناء إبراهيم علي الجديعي

دعوة عربية متوافقة مع الجوال، مع تسجيل الحضور وحساب القطة وإرفاق الإيصالات ولوحة إدارة خاصة.

## الوظائف

- عدّادات رمضان وعيد الفطر ورابع العيد حسب أم القرى وتوقيت مكة.
- صاحبة التسجيل ضمن الحضور، وفئتها تحدد مبلغها دون تكرار الاسم.
- بطاقات قابلة للفتح والإغلاق للحضور الإضافيين، ومنع الأسماء المكررة في التسجيلات النشطة.
- إدخال الجوال بصيغة `05xxxxxxxx`، وتحويله إلى `+9665xxxxxxxx` عند الإرسال.
- إيصالات خاصة لا يطّلع عليها إلا الأدمن، واعتماد الدفع يدويًا.
- إعدادات واتساب، وإحصاءات الحضور، والإلغاء وتوثيق الاسترداد والأرشفة.

## الاستضافة المستقلة

المصدر محفوظ في GitHub، والتطبيق الكامل يعمل على Cloudflare Workers وD1 في حساب المالك، مستقلًا عن اشتراك ChatGPT. GitHub Pages وحده لا يشغّل قاعدة البيانات أو الإيصالات أو الرسائل.

تُحفظ الملفات في النسخة المستقلة في جداول D1 خاصة على أجزاء محدودة الحجم، وتُقرأ كتدفق. لا توجد روابط عامة للإيصالات؛ تنزيلها يمر عبر تحقق جلسة الإدارة. الحد الحالي للإيصال ٥ ميجابايت. إذا شُغّلت نسخة Sites بربط R2 فتستخدم R2 تلقائيًا.

فتح المستودع للقراءة لا يمنح صلاحية تعديل بيانات الحضور. التعديل يحتاج رمز الأدمن المخزن كسر تشغيل `ADMIN_KEY`. لا يحتوي المستودع على رمز الدخول أو بيانات حضور أو إيصالات.

## التطوير والتجربة

```sh
npm ci
npm run test:phone
npm run test:whatsapp
npx tsc --noEmit
npm run build:standalone
```

أنشئ `.dev.vars` محليًا، دون رفعه إلى GitHub:

```text
ADMIN_KEY=ضع_هنا_رمزًا_عشوائيًا_طويلًا
```

طبّق مخطط قاعدة البيانات المحلية:

```sh
npx wrangler d1 migrations apply DB --local --config wrangler.standalone.json --persist-to .wrangler/state
npm start -- --port 5199
```

مع إصدار workerd قديم لا يدعم تاريخ التوافق الموجود في الملف، حدّث أدوات Wrangler أو مرّر تاريخًا يدعمه إصدارك للمعاينة المحلية فقط.

## النشر من حسابك

1. غيّر `account_id` وإعدادات D1 في `wrangler.standalone.json` إذا نشرت على حساب آخر.
2. أنشئ قاعدة D1 واربطها باسم `DB`، ثم طبّق المهاجرات.
3. ابنِ وانشر مع سر الإدارة؛ لا تضع السر داخل ملفات المصدر:

```sh
npm run build:standalone
npx wrangler d1 migrations apply DB --remote --config wrangler.standalone.json
npm run deploy:standalone -- --secrets-file .dev.vars
```

الاستضافة تظل مرتبطة بحساب Cloudflare وحدود خطته. واتساب التلقائي يحتاج خدمة إرسال مستقلة وقالبًا معتمدًا؛ الأهالي يستقبلون الرسائل على واتساب العادي.

## GitHub Actions

كل دفع إلى main وطلبات الدمج تُفحص وتُبنى. النشر التلقائي معطّل افتراضيًا حتى يضيف المالك `CLOUDFLARE_API_TOKEN` إلى أسرار المستودع ويضبط المتغير `CLOUDFLARE_DEPLOY_ENABLED=true` وبيئة production. لا تُستخدم الأسرار في بناء طلبات الدمج من الآخرين.

## الإعدادات والهوية

الدخول: `/admin`، إعدادات الأرقام والرسائل والباركود: `/admin/settings`. تُحفظ مفاتيح واتساب مشفّرة في قاعدة البيانات ولا تُعرض بعد حفظها.

الشعار وبيانات المناسبة مملوكة لصاحب المشروع. ملفات خطوط ثمانية تُحمّل من مصدرها الرسمي ولا تُعاد استضافتها في المستودع. تبقى تراخيص المكتبات والأجزاء الخارجية كما في ملفاتها.
